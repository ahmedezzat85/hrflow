Modal & Form System — Add Employee (representative example)

Shared visual language intended for every modal in the app: sectioned fields instead of one flat grid, required/optional signaling, a de-emphasized optional block for invoicing fields, clean (non-grey) inputs, and a button that visibly loads during submission. Once approved, these same classes roll onto Bank Account, Raise, Behalf Vacation/Claim, Category, and Document Upload modals with no new design decisions needed.
