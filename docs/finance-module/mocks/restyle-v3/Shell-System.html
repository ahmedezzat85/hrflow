One shell, one look, every module

Anatomy

Module rail68 px, navy #16245e. Logo and one button per module the user can open (HR, Finance, Payroll, System; employees see Me). Pending count sits on the module. Always visible; a click opens the module landing page (D-010, D-015).
Sidebar232 px, white. Module name and one line, a Search button (Ctrl K opens the existing command palette), the D-014 groups in sentence case, items with a small topic-coloured icon tile and counts. Collapses to the rail.
Top bar52 px: the Finance v2 header for every page. Area tile, page title, group name; breadcrumbs on detail pages. Right: export, the bell and the account menu with theme and sign out (D-014). Finance keeps Add transaction.
Content28 px side padding, so the content column is the 1140 px the Finance v2 references already use. Finance pages do not change inside the frame.

Topic colours: the tile beside every title, the sidebar icon and the dialog header

Rules every screen follows (same as Finance v2)

Sentence case, no uppercase
Headers, labels and buttons. Only the sorted column shows an arrow, in brand blue.
Dates read like 15 Jan 2024
Ranges as 9–13 Oct 2026. Never ISO dates on screen.
Money right-aligned
Tabular figures, currency on every value, totals in a shaded row.
Filter pills with counts
28 px, the selected one filled brand blue, empty ones faded.
Row actions
One text button plus up to three borderless 30 px icons. No ⋯ menu. Every icon has an aria-label.
No raw gaps
Missing values read Not set, Not scheduled or Not given in muted ink. Never undefined.
One gradient card at most
Only the main figure on a dashboard. Other cards are white soft cards.
Bank wording
Employee bank account (HR) and company account (Finance) are always named in full.
Payroll truth
HRFlow estimate, portal-confirmed amount and variance stay side by side; missing bank details flag, never block.
